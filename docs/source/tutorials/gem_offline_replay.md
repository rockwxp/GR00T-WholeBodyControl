# GEM SMPL Offline Replay in MuJoCo

This workflow replays an offline `smpl_params.pt` produced by
[GEM/GENMO](https://github.com/NVlabs/GENMO) through SONIC's SMPL encoder and
MuJoCo deployment. It never sends commands to a physical robot.

## 1. Export a GEM motion

In the GEM environment, run the video-only demo:

```bash
python scripts/demo/demo_smpl_hpe.py \
  --video path/to/input.mp4 \
  --ckpt_path inputs/pretrained/gem_smpl.ckpt \
  --no_render
```

The result is normally written as `outputs/<video-name>/smpl_params.pt`. The
replay tool uses `body_params_global` by default.

## 2. Validate the conversion

From the GR00T-WholeBodyControl repository root:

```bash
source .venv_sim/bin/activate
python gear_sonic/scripts/replay_gem_smpl.py \
  /absolute/path/to/smpl_params.pt \
  --dry-run
```

The command validates tensor shapes, reads the source FPS and retained frame IDs
from GEM metadata, fills dropped frames, resamples rotations to 50 Hz using
SLERP, computes the 24 local SMPL joints, and packs one SONIC protocol-v3
message. Use `--source-fps 30` only to override missing or incorrect metadata.

`torch.load` runs in safe, weights-only mode by default. If an older trusted
local GEM file contains unsupported pickle objects, add `--allow-unsafe-load`.
Never use that option on an untrusted file.

## 3. Tested three-terminal workflow

The following commands were tested with:

```text
/home/xiaopeng/workspace/GENMO/outputs/webcam/cam4_20260730_103732_781236/smpl_params.pt
```

Use three terminals and follow the order below. The publisher and deployment
must use the same ZMQ port and topic.

### Terminal 1: start MuJoCo

```bash
cd /home/xiaopeng/workspace/GR00T-WholeBodyControl
git switch feature/gem-sonic-offline-replay
source .venv_sim/bin/activate
python gear_sonic/scripts/run_sim_loop.py
```

This starts the Unitree G1 MuJoCo simulation and its DDS bridge. Leave this
terminal running.

### Terminal 2: start SONIC

```bash
cd /home/xiaopeng/workspace/GR00T-WholeBodyControl/gear_sonic_deploy
bash deploy.sh \
  --input-type zmq \
  --zmq-host localhost \
  --zmq-port 5556 \
  --zmq-topic pose \
  sim
```

The deployment arguments mean:

| Argument | Meaning |
|---|---|
| `--input-type zmq` | Receive the reference motion from a ZMQ publisher |
| `--zmq-host localhost` | Connect to the publisher on this computer |
| `--zmq-port 5556` | Connect to TCP port 5556 |
| `--zmq-topic pose` | Subscribe to messages whose topic is `pose` |
| `sim` | Run against MuJoCo instead of a physical G1 |

Then perform these steps:

1. Enter `y` if the script asks for confirmation.
2. Wait for `Init Done`.
3. Press `]` in Terminal 2 to start the SONIC policy.
4. Click the MuJoCo window and press `9` to place/drop the robot into the
   simulation.
5. Wait for G1 to stand stably.
6. Do **not** press Enter in Terminal 2 yet. First start Terminal 3 so that the
   ZMQ publisher has bound its port.

Press uppercase `O` in Terminal 2 for an emergency stop.

### Terminal 3: load and publish the GEM motion

```bash
cd /home/xiaopeng/workspace/GR00T-WholeBodyControl
source .venv_sim/bin/activate
python gear_sonic/scripts/replay_gem_smpl.py \
  /home/xiaopeng/workspace/GENMO/outputs/webcam/cam4_20260730_103732_781236/smpl_params.pt \
  --start-frame 116 \
  --lead-in 3 \
  --hold-last 2
```

Wait until Terminal 3 prints:

```text
Press Enter here to begin offline playback
```

Now press Enter once in Terminal 2 to enable ZMQ streaming, return to Terminal
3, and press Enter there to start playback.

The tested playback arguments mean:

| Argument | Meaning |
|---|---|
| `smpl_params.pt` | Offline SMPL motion generated by GEM/GENMO |
| `--start-frame 116` | Skip the first 116 retained GEM results, where the subject is not fully visible in this capture |
| `--lead-in 3` | Publish the first selected pose for 3 seconds before the motion starts |
| `--hold-last 2` | Publish the final pose for 2 seconds before stopping |

For this capture, GEM retained 660 results from source-frame IDs 0 through 663
and omitted four early frames. Therefore retained-result index 116 corresponds
approximately to source video frame 120. `--start-frame` and `--end-frame`
select indices in the retained GEM result arrays, not values from
`result_ids`.

When the non-looping replay finishes, the publisher exits after the final-pose
hold. Press uppercase `O` in Terminal 2 before shutting down the deployment.

## 4. Replay options

All replay options are:

| Option | Default | Meaning |
|---|---:|---|
| `--source-fps FPS` | GEM metadata | Override the source frame rate |
| `--target-fps FPS` | `50` | SONIC publication and interpolation rate |
| `--port PORT` | `5556` | ZMQ PUB port; must match Terminal 2 |
| `--topic TOPIC` | `pose` | ZMQ topic; must match Terminal 2 |
| `--window N` | `5` | Number of frames in each rolling protocol-v3 message |
| `--parameter-group GROUP` | `body_params_global` | Replay `body_params_global` or `body_params_incam` |
| `--start-frame N` | `0` | First retained GEM result index, inclusive |
| `--end-frame N` | end of motion | Final retained GEM result index, exclusive |
| `--lead-in SECONDS` | `1` | First-pose hold before playback |
| `--hold-last SECONDS` | `1` | Final-pose hold after playback |
| `--loop` | off | Repeat the selected motion continuously |
| `--no-wrists` | off | Disable approximate G1 wrist targets |
| `--no-wait` | off | Start publishing without waiting for Enter |
| `--dry-run` | off | Validate and convert without opening a ZMQ publisher |
| `--allow-unsafe-load` | off | Permit legacy pickle loading for a trusted local file only |

Keep `body_params_global` unless diagnosing a world-frame estimation problem.
The bridge converts SMPL Y-up coordinates to SONIC's Z-up convention and emits
scalar-first `(w,x,y,z)` root quaternions.

To validate the tested range without starting MuJoCo or SONIC:

```bash
cd /home/xiaopeng/workspace/GR00T-WholeBodyControl
source .venv_sim/bin/activate
python gear_sonic/scripts/replay_gem_smpl.py \
  /home/xiaopeng/workspace/GENMO/outputs/webcam/cam4_20260730_103732_781236/smpl_params.pt \
  --start-frame 116 \
  --dry-run
```

To replay continuously, add `--loop`:

```bash
python gear_sonic/scripts/replay_gem_smpl.py \
  /home/xiaopeng/workspace/GENMO/outputs/webcam/cam4_20260730_103732_781236/smpl_params.pt \
  --start-frame 116 \
  --lead-in 3 \
  --hold-last 2 \
  --loop
```

Use Ctrl-C in Terminal 3 to interrupt playback. The controller remains active
until it is stopped separately in Terminal 2.
